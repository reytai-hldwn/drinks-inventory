# 宏穩茶水間 · Holdwin Pantry

公司飲料的手機網站：同事開冰箱、看品項、許願；管理者在倉庫盤點與記錄到貨。採用暖白香檳金與公司 H 圖標，包含 32 款供應中飲料與 8 款歷史品項。

## 目前功能

- 牛奶／豆漿放在第一層，其餘依茶飲、咖啡、果汁、汽水與其他分類；八種包裝各有不同示意外觀。
- 關門顯示「點擊打開冰箱門」，開門動畫完成後才可在冰箱內向下滑動；支援手機及減少動態設定。
- 寬螢幕為雙門玻璃冰箱，手機為單門；依冰箱實際寬度自動切換。
- 同事的冰箱只顯示品項與包裝，**不顯示餘量**。
- 商品照片與示意圖可混用；Milkis 已使用確認的商品照片，其他品項暫用示意圖。圖片上傳與自動去背延後至首版上線後處理。
- 倉庫清單顯示實際紀錄庫存，**10 包／瓶／罐以內（含 10）標紅**；未盤點顯示待盤點，每箱數量也不擅自填入。
- 管理入口免登入；盤點及到貨入庫必填登記人，自動保存時間與數量。定期盤點校正日常取用，無須每天記錄。
- 願望卡有「我也想喝」與贊同人數，同一瀏覽器對同一願望只計一票。
- 停買改為歷史品項，保留庫存與所有舊紀錄；之後可重新上架。
- 管理者可複製補貨清單與匯出盤點／入庫紀錄。

## 本機試用

`demo.html` 是可獨立開啟的單檔示範，內嵌程式與品牌圖片。若瀏覽器限制本機檔案，請啟動開發伺服器：

```sh
npm run dev
```

本機示範的修改只存在同一個瀏覽器；這不是正式共用模式。32 款的初始數量、箱裝數量都等待實際輸入，不會沿用舊示範數字。

## 正式共用：Google 表單＋私人試算表

已選用 Google，**不必使用 Supabase**：

- 冰箱讀取品項與願望；免登入的管理入口另外讀取庫存及登記人紀錄。
- 許願、贊同、盤點及入庫使用四張公開 Google 表單，不要求同事登入；兩張庫存表單必填登記人。
- 同一瀏覽器的贊同會使用匿名識別碼去重。Google 票數只在表單實際送出、同步後更新，不預先增加。
- 持有網站連結者都能查看倉庫並登記數量。原始 Google 試算表保持私人，擁有人仍須授權建立及發布表單。
- 試算表包含 `Catalog`、`Warehouse`、`Archive`、`History`、`WishReview`、`WishVotes` 與表單入口。

Google 設定程式已備妥，但尚未替使用者建立或授權真實 Google 資源。請先依 [Google 設定步驟](docs/GOOGLE-SETUP.md) 建立表單與試算表，再依 [網站上線步驟](docs/GO-LIVE.md) 發布 GitHub Pages。不得將本機畫面或測試成功當成已上線。

## 開發與驗證

Node.js 24、Python 3 即可，不需要 `npm install`：

```sh
npm run build       # 更新單檔示範；同時驗證內嵌模組語法
npm run check
npm test
npm run dev
```

正式站以 `GOOGLE_SCRIPT_URL` 設定已發布的 `/exec` 網址，再執行 `npm run build:site`。建置只輸出網站必要檔案到 `dist/`，不包含試用檔、設定腳本、測試或截圖；沒有共用網址會拒絕建置，不會發布各手機獨立的本機示範。

`supabase/` 與舊設定文件保留為選配介接參考，目前的正式上線流程以 Google 為準。
