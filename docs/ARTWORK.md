# 辦公室手繪底圖

依使用者提供的辦公室空間原照重新繪製暖白、香檳金、咖啡色細線水彩插畫。使用獨立的原尺寸插畫素材，頁面標題、Logo、操作與飲料照片仍由網站呈現。

新桌機素材各約 157 萬像素，相較舊設計稿內的桌機區域 1074 × 560（約 60 萬像素）具有更多原生細節。尺寸按實際生成檔記錄，不把插值放大的版本標為原生高解析圖。

## 已套用的構圖要求

- 白色四門冰箱與深色十字框；兩張便條貼及膠帶已移除。
- 長桌兩側各有一排木製高腳椅，桌面延伸至畫面右側邊緣。
- 保留電視、飲水機、櫃體及右側城市窗景，電視不加中央亮面。
- 手機維持使用者原本確認的單門插畫，手機不下載新桌機底圖。
- 標題與公司 H 圖標沿用網站既有字型及正式圖檔。

## 網站呈現

桌機依展示區的寬高比選擇橫幅或窄高素材。PNG 保持比例，四扇動畫門與可點擊範圍使用同一座標系。共享 SVG 圖片定義讓四扇門重用同一張底圖，僅為目前構圖載入圖片。

冰箱左側的小型雲朵框以網站手寫字型顯示「點擊打開冰箱」，不帶指向性的尖角尾巴；旁邊的短小金色箭頭有向上迴圈、實心箭頭與細微亮邊。雲朵框保持在可見範圍，箭頭依圖片裁切與縮放重新連到實際門片；文字不烘焙進圖片，放大仍清楚。標示本身可點擊並支援鍵盤；開門後隱藏，關門後恢復。手機保留原操作提示。

桌機開門約 0.65 秒：四扇門旋轉打開時，門後可見帶有實際飲料照片的簡單層架與抽屜，接續放大淡入完整飲料架，動作互相重疊而不在空白凹槽停頓。這些門後的內容是裝飾，沒有額外的操作或庫存數字。搜尋與分類在動畫完成後顯示，避免展示區高度在開門時改變。系統設定減少動態時直接顯示飲料架，手機沿用既有動畫。

更換插畫時，需同步校對 `js/fridge.js` 的門片、凹槽、點擊區與箭頭座標，再執行 `tests/browser-scene.mjs` 檢查桌機、窄高視窗、手機及視窗縮放。
