# 茶水間人氣排行榜

管理後台功能列的「消耗排行榜」提供飲料與零食兩類。前三名以人氣卡片呈現，後方按每週平均消耗排列；可依最近 30 天、90 天、全部紀錄、分類、包裝單位、品名／口味與是否包含歷史品項篩選。搜尋不會打斷輸入，也不重讀共用資料。

依使用者指定，飲料預設將包、瓶、罐一起比較每週消耗件數，品項旁保留原單位；也可單獨查看某一包裝。零食保留單位篩選。同品名的零食可展開查看其他口味的每週消耗，沒有足夠盤點資料的口味會顯示等待狀態。泡麵與碳粉不列入排行榜。

每一個完整盤點區間的消耗估算為：

> 上次實際盤點數量 ＋ 期間到貨入庫數量 − 本次實際盤點數量

將合格區間的消耗合計，除以合計觀察工作日天數，再乘以 5；週末不計入，因此不是把長短不同區間的速率直接平均。尚未完成第二次盤點、只有入庫、連續觀察仍未滿一個工作日或未來的紀錄不產生估算。後續新到貨也不回填成已消耗。

連續的短盤點區間會合併；最後一段不足一個工作日時，延伸前一段有效觀察。例如 11/2 09:31 盤點 39、11/4 10:40 盤點 19、11/5 08:08 盤點 16，會計入總共消耗 23，而不是因為最後兩次未滿 24 小時而漏掉 3。單獨幾分鐘的盤點不會被外推成每週用量；異常或不連續的區間也不會被合併。

只使用選定期間內的完整區間，不把跨期間的盤點差額按天數分攤成虛構的每日消耗。負差額、異常數量與整段沒有庫存的區間排除；同一品項其他有效區間仍可採計。期初和期末都是 0、但期間確有到貨並消耗掉時，仍屬有效區間。

沒有足夠資料不等於沒有消耗。等待資料的品項另放收合清單；已完成有效盤點但差額為 0 的品項另列「本期未觀察到消耗」，不頒發虛構人氣名次。展開每個排名可以看到盤點區間、數量計算與區間平均速率；盤點差額也可能包含報廢或調整，因此介面明示這是估算。

排行榜重用現有倉庫與已採計事件，完全唯讀，不新增資料表或登記數量。紀錄按品項分組與排序後保留於記憶體，篩選不發出額外 Google 請求。排行榜顯示時每分鐘讀取最新紀錄；搜尋及篩選維持本機運作，背景更新不重建輸入欄位。離開分頁或有未送出輸入、開啟對話框時暫停背景讀取。冰箱的人氣摘要只在展開時讀取，快取最多一分鐘；手動重新讀取會繞過快取。盤點後與其他裝置的新紀錄會使舊摘要失效，先前發出的舊請求不能覆蓋新結果。

完整修正需要更新原 Apps Script Code.gs 並發布原部署的新版本，使冰箱摘要端點與後台採用相同的連續區間計算；不用執行函式或更換網址。
