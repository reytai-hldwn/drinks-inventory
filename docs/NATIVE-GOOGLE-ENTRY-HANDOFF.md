# 原生表單串接 Google 試算表：接續結果

2026-11-02：已接續完成原生送出流程，保留既有設計、Google 試算表與歷史。桌機 1440px／手機 390px 的五種操作均通過攔截端點的瀏覽器整合測試，沒有跳轉 Google 表單或開新分頁。

## 實作與驗證

- `Code.gs` 提供五種指定寫入操作與唯讀儲存回條；`WebsiteRequests` 保存準備資料，固定事件 ID 避免逾時或部分失敗後重複寫入。
- 網站沿用 demo 原生表單，等待 Google 確認才顯示成功；錯誤保留輸入，送出中阻擋重複點擊，重新整理後重試沿用同筆識別碼。
- 新增測試涵蓋匿名飲料／零食許願、必填贊同姓名、瀏覽器去重、部分盤點、0、整箱／零散到貨、新飲料待盤點與每箱 24、重複品名、公式跳脫、分塊資料及部分儲存恢復。
- 確認儲存後，即使讀取失敗或瀏覽器儲存空間清理失敗，仍保留成功結果。
- 測試使用模擬試算表，不向使用者正式 Google 資料送出測試紀錄。
