# 今日補給扭蛋：飲料與量化交易幸運籤

第一版以「轉一顆飲料，順便接收今天的好訊號」為主題。白、香檳金與咖啡色的手繪線條扭蛋機，配上像幸運餅乾紙條的卡片。機台是小型 SVG 與 CSS，不下載大型動畫、影片或遊戲引擎。飲料沿用冰箱既有去背小圖及資訊視窗。

每天依台灣日期抽一顆，同一瀏覽器保留當日籤詩與飲料，重新整理或另一個分頁仍可查看；午夜或隔天回到頁面會重置。跨裝置各自保存，沒有登入或蒐集姓名。轉動約 0.65 秒，裝置設定減少動態效果時直接顯示；飲料推薦背景讀取，幸運籤不等遠端資料，切換頁面不會被卡住。

## 飲料推薦與狀態

推薦僅從仍供應中、最近紀錄有正庫存的飲料隨機挑選；無庫存、歷史與尚未確認數量的品項不列入。各品項等機率，與消耗排行榜獨立，不讓熱門飲料一直壟斷扭蛋。抽到後可開啟既有飲料資訊，查看包裝、成分與營養標示。

若目前沒有適合推薦的飲料，先保留幸運籤，之後可再看飲料；遠端讀取失敗也能重試，籤詩與當日次數維持原結果。扭蛋提供推薦，不登記領取或扣除庫存；實際取用仍由原盤點與入庫流程反映。

## 第一版與後續方向

第一版程式已實作機台、每日結果保存、三種籤詩機率、飲料背景推薦、營養資訊入口、鍵盤操作與減少動態效果。資料只讀，抽籤不寫試算表。對外的推薦讀取只回傳可選 ID，不下載倉庫數量、盤點紀錄或登記人。

前台 `#gacha` 可先作為試玩入口。正式導覽入口與飲料推薦，會在更新整合版 Apps Script 原部署後一起啟用；此前直接試玩仍可抽幸運籤，不假裝已有可用飲料。整合版同時包含無庫存處理，因此之後只需更新一次原部署，不用重新執行 setupOnce 或更換網址。

後續可再評估籤詩收藏、分享籤紙、連假特別籤與節日機台外觀。這些不會在第一版加入額外資料寫入或初始載入負擔。
