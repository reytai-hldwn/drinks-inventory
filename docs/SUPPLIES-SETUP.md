# 啟用泡麵、碳粉庫存與保存期限

網站後台分成「飲料／泡麵／碳粉」。泡麵與碳粉存放在原試算表的獨立工作表，沿用目前 Google Apps Script 部署網址；原飲料、願望及其紀錄繼續使用。

## 1. 更新原 Apps Script 專案

1. 開啟 [最新版 Code.gs](https://github.com/reytai-hldwn/pantry/blob/main/google-apps-script/Code.gs)，按 **Raw** 開啟純文字，按 `Ctrl+A`、`Ctrl+C` 複製完整內容。
2. 到 [Google Apps Script](https://script.google.com/home)，開啟目前提供網站 `/exec` 網址的原專案。
3. 左側選 **Code.gs**，按 `Ctrl+A` 全選、`Ctrl+V` 貼上，再按 `Ctrl+S` 儲存，等畫面顯示已儲存。
4. 這次不需執行 `setupOnce`。原專案的 Script Properties、原試算表及部署網址會繼續使用。

## 2. 更新目前正在使用的部署

1. 右上角按 **部署 → 管理部署**。
2. 左側選目前網站正在使用的「網頁應用程式」部署。
3. 按右側的 **鉛筆圖示（編輯）**。
4. **版本**選擇 **新版本**，說明可填「泡麵、碳粉與泡麵保存期限」。保留原執行身分與存取設定。
5. 按 **部署**；若 Google 要求授權，使用原帳號完成。
6. 沿用原本的 `/exec` 網址，不必更改 GitHub Variables。

只按儲存不會更新網站呼叫的正式版本，需完成上述「管理部署 → 新版本 → 部署」。

## 3. 回網站確認

1. 開啟 [宏穩茶水間](https://reytai-hldwn.github.io/pantry/)，按 **管理後台 → 倉庫庫存**。
2. 點 **泡麵** 或 **碳粉**。若仍顯示更新提示，按網站右上角 **重新整理**，再確認上一節已更新正確的部署。
3. 下列品項先顯示「待盤點」，沒有預填現有數量：

   | 分類 | 品項 | 單位 |
   | --- | --- | --- |
   | 泡麵 | 來一客海鮮 | 杯 |
   | 泡麵 | 滿漢大餐牛肉麵 | 碗 |
   | 泡麵 | 拉麵道味噌拉麵 | 杯 |
   | 泡麵 | 拉麵道豚骨拉麵 | 杯 |
   | 泡麵 | 奶油白醬辣火雞麵 | 杯 |
   | 碳粉 | 黑色碳粉 | 盒 |
   | 碳粉 | 黃色碳粉 | 盒 |
   | 碳粉 | 紅色碳粉 | 盒 |
   | 碳粉 | 藍色碳粉 | 盒 |

4. 實際清點後，按單一品項的 **盤點**，或上方 **盤點這一類**；填登記人與實際數量。空白保留原紀錄，填 `0` 才代表實際為零。
5. 第一次成功登記時，原試算表會自動新增 `SupplyCatalog`、`SupplyHistory`、`SupplyWarehouse`。前兩張是來源資料，後者是產生的庫存檢視；查閱清單不會建立或改寫紀錄。

## 4. 快速入庫與保存期限

1. 點品項旁的 **＋ 快速入庫**。
2. 填登記人與本次到貨數量，依該品項的「杯／碗／盒」登記。兩類均不使用整箱換算。
3. **泡麵必填保存期限**，以包裝上的有效日期為準；不能填早於今天的日期。碳粉不需填保存期限。
4. 相同品項若有不同保存期限，分次入庫。每次都會保留自己的批次、原入庫量、日期、登記人及備註，新日期不覆蓋舊批次。
5. 按 **確認入庫**，收到 Google 儲存確認才顯示成功。

總庫存＝最近一次實際盤點＋之後到貨。尚未完成首次盤點時，入庫仍會保存，但總量繼續顯示「待盤點」，不會把未知的原庫存當成零。

## 5. 查看效期提醒

- 泡麵庫存表的 **保存期限／入庫批次** 欄顯示較早的保存期限；展開可查看各批次。
- 預設 **30 天內到期**顯示近效期提示；當日顯示「今天到期」，超過日期顯示「已到期」。判斷以台北日期為準。
- 批次上顯示的是原入庫數量，實際剩餘需現場核對。
- 確認某批已用完或已移除後，按 **此批已用完**、填登記人，再確認，可解除該批提醒。這個標記保留紀錄，總庫存另以實際盤點校正。
- 當實際盤點為 `0` 時，之前各批次的提醒自動結束；原入庫與效期紀錄仍保留。
- 既有庫存沒有保存期限資料時顯示「效期待補」，不推測日期。
- 若盤點既有庫存或上調數量時沒有對應的入庫效期，另顯示效期待核對提示；新入庫的日期不代表舊庫存也已核對。

這次 Google 端更新需由專案擁有人完成；網站程式無法替你發佈 Google 帳號內的 Apps Script 部署。更新前，飲料流程繼續運作，泡麵與碳粉顯示品項與明確提示，新增儲存功能暫不開放。
